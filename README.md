# esther021008-INTRODUCTION-TO-DATABASE-FINAL-PROJECT-BIT1201_GROUP1
Public Health Clinic Records System

Overview

The Public Health Clinic Records System is a MySQL-based database project designed to improve the management of healthcare information within public health facilities. The system stores and manages patient records, health worker information, appointments, clinic visits, diagnoses, and treatment records in a structured relational database.  

Features

* Patient registration and record management
* Health worker information management
* Appointment scheduling
* Patient visit tracking
* Diagnosis recording
* Treatment management
* SQL queries for data retrieval and analysis
* User management and database security

Database Structure

The system consists of six main tables:

* Patient
* HealthWorker
* Appointment
* Visit
* Diagnosis
* Treatment

These tables are connected using primary and foreign keys to maintain data integrity and support efficient data retrieval.  

Technologies Used

* MySQL
* SQL (DDL, DML, and Queries)

Database Features

* Primary Keys
* Foreign Keys
* AUTO_INCREMENT
* NOT NULL Constraints
* UNIQUE Constraints
* CHECK Constraints
* Relational Database Design

These features help ensure consistency, accuracy, and security of the stored data.  

SQL Operations Included

The project demonstrates:

* Database creation
* Table creation
* Data insertion
* UPDATE operations
* DELETE operations
* SELECT queries
* WHERE filtering
* ORDER BY sorting
* Aggregate functions (COUNT, AVG)
* LIMIT clause
* User creation and privilege management  

Security

The database implements basic security practices, including:

* User authentication
* Access privileges
* Password management
* Protection of confidential patient information

These measures help maintain data confidentiality, integrity, and availability.  

Project Objective

The primary objective of this project is to design and implement a relational database that enables healthcare facilities to efficiently manage patient information while ensuring data integrity, consistency, and security.  

Future Improvements

Conclusion

This project demonstrates the practical application of relational database concepts in healthcare management. By organizing patient records and clinic operations efficiently, the system contributes to improved healthcare service delivery in public health facilities.
